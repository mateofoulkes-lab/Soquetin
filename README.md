# Recuperador de password de Soquetin — V1

Prototipo web 3D estático listo para publicar.

## Incluye
- Dungeon cerrado, 5 m de altura.
- Sala inicial, tres desafíos y sector final.
- Dos grillas 5×6 con las letras exactas del croquis.
- Patrón seguro idéntico en las tres salas.
- Losetas falsas que se rompen y desaparecen.
- Sala de columnas sobre lava a 10 m.
- Personaje provisional de 0,50 × 1,20 m.
- Movimiento a saltitos, salto alto, control aéreo.
- Cámara de tercera persona con repliegue cerca de muros.
- Controles PC y controles táctiles para móvil horizontal.
- Muerte en lava y respawn a los 0,5 s.
- Carteles placeholder.

## Controles
PC:
- WASD / flechas: movimiento
- Mouse: cámara
- Espacio: salto alto

Móvil:
- Control izquierdo: movimiento
- Control derecho: cámara
- SALTO: salto alto

## Publicación
`index.html` es el único archivo necesario.
Usa Three.js desde jsDelivr, por lo que requiere conexión a Internet.
